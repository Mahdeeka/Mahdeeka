## إعادة التوليد
```bash
pip install opencv-python-headless pillow numpy
python prep.py          # قص الصور الحقيقية واستخراج الشعارات من التصاميم الأصلية
python make_posters.py  # بناء الشرائح الثلاث (Chrome يرسم النص العربي)
```
النصوص كلها في `make_posters.py` (دوال `cover`, `moderator`, `guest`).
الصور الحقيقية لم تُرسم من جديد: قُصّت فقط مع تعديل لوني خفيف جدًا. الشعارات مأخوذة من التصاميم الأصلية.
